# Shared test diagnostics

Each test page has the same eight analysis sections, built from fetched results by
`scripts/test_diagnostics.py`. They contain real measurements only. Gridlines are
disabled, code families keep their existing colours, and variants use line styles.
Abel et al. and external codes are separated when a combined figure would be crowded.

1. Density and magnetic-vector L1, L2 and Linf errors against physical time.
2. Endpoint L1 errors against resolution.
3. The same endpoint errors against resource cost, separating GPU-hours and CPU core-hours.
4. Mass, total energy and momentum budgets, plus component-energy histories.
5. Common cell-centred RMS/max divergence, with native CT face divergence separately.
6. Velocity and magnetic spectra and reference ratios at a common time and grid.
7. Completion/finite-state matrix, sampled floor fractions and nonpositive pressure.
8. Recorded runtime and actual endpoint timings; unrecorded intermediate progress is not inferred.

For a subset, give test identifiers to `test_diagnostics.py`. Figures are PNG/SVG
pairs under `progress/media/analysis/<test>/`; the page registry is
`progress/test_analysis.json`. Each test has downloadable `data.json` and `runs.csv`
with source paths, settings, measurement scopes, and all fetched seeds. Scientific
history plots select seed 42 consistently; the driven pilot displays its own seeds.

## Accuracy and references

Error histories use the recorded analytic-reference norms wherever present. For
nonlinear tests, the builder subtracts actual saved states from a time-matched,
block-averaged higher-resolution AthenaK reference. It does not promote a same-grid
run to truth, compare unrelated physical times, or fill in missing errors. Markers
show available snapshots, which may be sparse. A 3D slice never becomes a
full-volume error metric. Scalar and vector errors use the corresponding reference
L1/L2/Linf norm; zero-field blasts use absolute magnetic error instead of division
by zero. Numerical references are comparisons, not exact truth: reference
convergence has not been established for every case. Late chaotic flows also need
statistical comparisons.

Convergence and accuracy/cost require a complete finite run at the requested
endpoint. CPU core-hours use the environment's launcher rank count where present;
otherwise the planned rank count is explicitly identified. GPU and external timing
scopes differ and are retained in the run table. Repeat timings exclude known
nonfinite outputs. Missing raw states and reference files are recorded under
`progress/media/analysis/missing_snapshots.txt`.

## Other measurements

Abel's planar GPU runs measure an N³ allocation; external planar codes measure N²
cells. Floor fractions divide by that actual measured count. They are observations
at output times, not an instrumented tally of every internal floor intervention.
Common divergence and projected/sampled moving-mesh fields differ from a code's
native constraint, so native diagnostics are labelled separately. Relative
divergence is undefined for zero field. Planar spectra are computed from saved
cell-centred states using shell sums with round(|k|) bins, matching the sweep's
3D convention; 3D spectra use the recorded full-volume measurements. Uniform
states have no meaningful nonzero-mode spectrum. Tiny reference spectral power
is excluded from ratios.

The driven pilot is split by target Mach number. It has independent force
realizations, no spatial truth reference, and energy/momentum injection. Its
spatial-error, convergence and accuracy/cost sections explain why those metrics
are unavailable. Total-energy gain is not labelled a conservation error, and
missing injected-work records are not invented. The existing statistical
comparisons remain on the turbulence page.

## Missing data

MHD-ALE is read automatically from the sweep results directory (or additional
directories in `MHD_ANALYSIS_EXTRA_RESULTS`) once its standard-format records are
fetched. Applicable tests show missing data until then. RAMSES II has throughput
measurements only and is not a science curve on these pages. Unrun Float32 checks
are not presented as measured results.

On the Mac, lyxia can fetch existing missing inputs, without launching any jobs:

```bash
bash scripts/fetch_test_analysis.sh
```

The list is generated by `plan_test_analysis_fetch.py`: planar 128² histories,
planar endpoints at other grids, small 64³ full-volume histories, environment
records, and MHD-ALE records. Remote files that do not exist are skipped and
reported. Larger 3D spatial-error comparisons need a separate fetch. The scratch
inventory provides only an older size estimate.

## Validation

```bash
.venv-movie/bin/python scripts/check_test_diagnostics.py
```

These checks cover vector-direction errors, full-volume norms, zero-reference
normalization, nonfinite/incomplete runs, rejection of slices as volume errors,
exclusion of nonfinite timing repeats, and the planar spectrum's Parseval
normalization. Inspect representative figures and validate generated links before
publishing. Follow `HANDOFF.md` for publishing and the site's privacy rules.
