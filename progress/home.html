Benchmarking magnetohydrodynamics codes

The same magnetohydrodynamics (MHD) test problems run with 13 codes on GPUs and CPUs, on grids from 32 to 512 cells a side, each measured against an exact solution or a much finer reference run, to find which codes and settings give the most accuracy for the computing they use, problem by problem. It began with Tom Abel's new GPU kernels (Abel et al.) and grew to most public MHD codes. Every number on these pages is computed from the run records.
